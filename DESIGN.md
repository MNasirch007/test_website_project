# Renter design

Renter is a calm, practical workspace for Pakistani car and bike rental owners. The bundled Airtable design study informs its light canvas, restrained typography, hairline borders and workflow-first hierarchy; Renter uses its own forest-green identity.

- Palette: canvas #f7f9f8; white surfaces; ink #162821; muted #73817a; forest #153f30; action #247a58; mint #e9f4ee. Amber and blue only communicate status.
- Type: Inter when available, system sans fallback. Main heading 28px/600, section headings 17px/600, body 14px, supporting labels 12px.
- Layout: 232px persistent navigation, 76px header, 32px main padding; four summary metrics, revenue and fleet panels, pickup/return schedule, activity. Mobile uses a drawer and stacked panels.
- Components: 10–14px radii, understated 1px borders, 40px controls (44px on touch), clearly labeled icon buttons and focus outlines.
- Data: sample records are identified; all metrics come from actual saved records. Security deposits are never revenue. Blank states explain the next action.
- Motion: short opacity/translation transitions, disabled for reduced motion. No decorative gradients or misleading claims.
- Access: owner dashboard requires sign-in. Customer booking requests do not expose private customer records. First publication remains private for review.
