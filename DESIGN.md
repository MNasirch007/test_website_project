# Renter design

Renter follows the user-supplied `web_concept _design.md`: warm paper, ink typography, sharp application panels and rounded primary actions. The Cursor reference informs the visual language; the content and workflows belong to Renter.

- Palette: canvas #f7f7f4, surface #f2f1ed, ink #26251e, muted #716f65, hairline #e6e5e0. Orange #f54e00 marks the wordmark; small text links use darker #c13c00 for readable contrast. Gold #c08532 is reserved for status/chart detail. No saturated section backgrounds.
- Type: Arial/system sans substitutes for unavailable CursorGothic; self-hosted EB Garamond provides 17–21px editorial prose. UI labels, forms, tables and buttons remain sans-serif. The bundled font includes its OFL license. Headings use regular weight; numeric summaries use tabular figures.
- Layout: owner workspace retains its practical navigation and density, with a 64px header and 1300px content cap. The booking page uses a spacious hero, window-framed vehicle illustration, fleet cards, three-step explanation and oversized closing CTA. Mobile uses a drawer and stacked panels.
- Components: 0px card/panel corners, 4px fields, 2px badges and full-pill primary actions. Hairline borders separate working surfaces; layered shadows are limited to floating dialogs and showcase windows. Touch controls retain 44px minimum height where needed, labeled icon buttons and visible focus outlines.
- Data: sample records are identified; all metrics come from actual saved records. Security deposits are never revenue. Blank states explain the next action.
- Motion: short opacity/translation transitions, disabled for reduced motion. No decorative gradients or misleading claims.
- Access: owner dashboard requires sign-in. Customer booking requests do not expose private customer records. First publication remains private for review.
